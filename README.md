\#UPI Transaction EDA



Exploratory data analysis of daily UPI transaction volume and transaction value in India.



\##About the Project



This project investigates patterns, trends, variability, anomalies, and temporal characteristics in daily UPI transaction activity.



The dataset was compiled from data published by the National Payments Corporation of India (NPCI), collected across different periods and subsequently merged into a single dataset for analysis.



\## Current Analysis



The exploratory analysis currently includes:



\- Dataset preprocessing and cleaning

\- Descriptive statistics

\- Time-series trends

\- Daily and monthly patterns

\- Day-of-week analysis

\- Anomaly detection

\- Trend- and seasonality-adjusted anomaly analysis

\- Time-series decomposition

\- Residual analysis



The analysis is exploratory and conclusions will be refined as the study progresses.
